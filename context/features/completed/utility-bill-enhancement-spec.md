# Utility Bill Enchancement

## Overview
In utility bill, populate the months , and randomize the fee paid

## Requirements
- In Caj Semasa (RM), this should be randomize the number between RM150.00 to RM250.00 , this number is the latest month charges.

- In Baki Terdahulu (RM), this should be randomize the number between RM150.00 to RM250.00

- In Jumlah Bil Anda (RM), this the sum of Caj Semasa (RM) + Baki Terdahulu (RM)

- In Sila bayar sebelum, the Date should be 1 month away from TARIKH BIL

- in Caj Bulanan (RM), this will show previous 6 months usage. populate last 6 months monthly usage and randomize the number between RM150.00 to RM250.00 
The background gey barchart should match the value

- In Pengunnaan (kWh) - do not change anything
