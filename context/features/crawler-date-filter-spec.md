# Crawler Date Filter

## Overview

Add a date filter in crawler section for user before starting to crawl.

## Requirements
- It should have from date and to date, Maximum past 2 months date, if older than that, prompt error 
- Reset button
- Add Last 1 day, 3 days, 7 days, 1 week, 1 month, 2 months option
- The filter date range should be send to handleCrawl()
